# Remote Server Agent Plugin for Config Studio 🖥️

Официальный плагин **Remote Server Agent** для [Config Studio](https://github.com/EdvardBaldanov/config-studio).
Позволяет управлять неограниченным количеством удаленных серверов (VPS, хосты, контейнеры) из единого интерфейса редактора.

## 🚀 Возможности

- **Мультисерверное переключение на лету**:
  - Быстрое переключение между локальным хостом (`Localhost`) и любыми удаленными серверами прямо из шапки редактора (Header).
- **Простое добавление серверов**:
  - Добавление инстансов Config Studio по URL (например, `http://192.168.1.100:8080` или `https://vps.mydomain.com`).
  - Поддержка токенов авторизации для защищенных серверов.
- **Модульность и лёгкость**:
  - Не нагружает приложение, если вы работаете только с локальными конфигами.
  - Устанавливается по требованию, как только появляется второй или третий сервер.

## 📦 Установка

В Config Studio откройте **Настройки (⚙️) → Плагины**:
1. Вставьте ссылку на репозиторий:
   ```
   https://github.com/EdvardBaldanov/config-studio-remote-agent
   ```
2. Нажмите **«Установить по URL»**.

Либо скачайте ZIP-архив репозитория и загрузите его через кнопку **«Установить из ZIP»**.

## 🖥️ Как запустить Config Studio на удаленном сервере (в режиме агента)

1. Скачайте бинарник `config-studio` на целевой сервер:
   ```bash
   curl -L -o config-studio https://github.com/EdvardBaldanov/config-studio/releases/latest/download/config-studio-linux-amd64
   chmod +x config-studio
   ```
2. Запустите его как демон или сервис systemd:
   ```bash
   ./config-studio --port 8080 --host 0.0.0.0
   ```
3. В плагине нажмите **«➕ Добавить сервер...»**, укажите IP и порт удаленного сервера — теперь файлы и конфиги этого сервера доступны в вашем редакторе!

## 🛡️ Требуемые разрешения

- `ui.panels` — регистрация выпадающего списка переключения серверов в верхней панели.
- `network.bind` — подключение к удаленным сетевым эндпоинтам.
